# 使用教學(2026-09-14 版)

線上網址:GitHub Pages(push 到 `main` 後自動更新)。資料每個交易日台北 16:13 由
GitHub Actions 更新一次,不是即時報價。所有你自己輸入的東西(追蹤、思考路徑、
個人事件)只存在瀏覽器 localStorage,換裝置要用「匯出/匯入」搬。

## 每天的看盤順序(建議)

1. **大盤狀況**:先看九宮格今天是哪一格。「系統性賣壓」「指數跌」的日子,爆量/
   FOMO 分頁頂端會出現黃色橫幅,提醒看多訊號要降級;橫幅裡會引用記分板「同狀態
   下這種訊號的命中率」,樣本不足會明講。往下捲有「事件日曆」,看 3 週內有沒有
   財報/法說/政策/除息。
2. **訊號記分板**:每個訊號(爆量、暴跌、可能會漲、虛漲、真跌、虛跌)之後 5/10/20
   日的命中率跟平均超額報酬。灰色 = 樣本不到 60,只能看方向感。展開分桶看「大盤
   當閘門」「均線合流」「籌碼合流」「事件日」「量比級距」哪個有差。**這一頁是整個
   系統唯一能告訴你「這套訊號到底準不準」的地方**,先看它再看訊號。
3. **爆量掃描 / 暴跌掃描**:新增「均線」欄(多頭排列/空頭排列/糾結)。記分板的
   `ma` 分桶會告訴你哪一種均線狀態下的爆量比較有用,先看那個再挑。
4. **FOMO / 暴跌FOMO**:可能會漲/虛漲、真跌/虛跌判定。同樣先看記分板的命中率。
5. **法人軌跡 / 兵棋推演**:量縮蓄勢的方向判斷、持倉的移動停利/ATR 停損總覽。
6. **個股查詢**:選一檔,meta 那行現在會多顯示:均線狀態、‼️接近前高、融資維持率、
   PE/PB/殖利率(TWSE)、📅 5 天內事件。
7. **追蹤**:卡片上 📅 = 3 天內有事件,‼️ = 接近前高,均線狀態一行。持倉的出場
   設定現在有「固定停損 %」(從均價算)可以填,旁邊會自動換算停損價。

## 思考路徑(做一檔股票的全套分析)

建立路徑 → 「+ 新起點」放第一格 → 每格選常用詞或自己打字 → 「+ 接續」往下長,
同一格按兩次就分岔,多選再「合併成新方塊」就會合。建議層次:大盤 → 產業流向/
個股量價/籌碼 → 催化劑時間軸 → 財報 → 估值試算 → 看多/看空分岔 → 決策 → 進出場
計算 → 事後檢討 checkpoint。範例檔在 `data/thinking-paths/`,追蹤分頁「匯入」→
「合併」就會進來。

- **估值試算**現在會自動帶入最新收盤價,以及用 TWSE 本益比反推的近四季 EPS
  (TTM 口徑),你要用預估 EPS 就自己改掉。資料不完整就勾「單一來源」讓文字帶 ⚠️。
- 方塊建立後文字鎖住,之後的想法用「新增更新」疊上去,不要覆蓋。

## 事件日曆怎麼用

- 要進記分板統計的事件,填在 repo 的 `data/events.json`(GitHub 網頁上直接編輯
  就好),格式看檔案裡的 note。
- 只是提醒自己的,直接在「大盤狀況」分頁的事件日曆表單新增,存在瀏覽器裡。
- 除權息預告不用填,自動從 TWSE 資料併進來。

## 資料回補(第一次要做一次)

GitHub → Actions → 「每日掃描」→ Run workflow,`archive_backfill_days` 填 `250`,
其他留預設。大約 15 分鐘,之後永久存檔就有一年的價格跟指數,記分板的 10/20 日天期
跟門檻掃描才有足夠樣本。平常不用再填。

跑完看 log 裡「更新全市場估值」那步的「欄位:」那行,確認 TWSE 回的欄位跟腳本預期
一致(這支還沒實跑過);對不上的話那步會軟失敗,其他步驟不受影響。

## 門檻掃描(進階,本機跑)

```
python scripts/tune_thresholds.py --signal scan --values 1.5,2,2.5,3 --horizon 10
```
一次只動一個參數;樣本不到 60 的列不要拿來下結論;改了門檻之後要用之後的新資料
再驗一次,不然就是過擬合。

## 產業別不對怎麼辦

編輯 `data/industry_overrides.json` 加代號 → 產業名稱,下次排程會自動套用,產業流向
那邊會把它移到新組、舊組補滿,不用整份重抽樣。目前只改了漢翔、亞航、長榮航太
(航太軍工)。

## 不會變的規矩

- 所有門檻(量比 1.5、振幅 3.5%、前高 85%、ATR 2.5 倍、固定停損 %…)都是經驗值,
  沒有一個經過回測。記分板就是拿來驗證它們的,樣本夠了再調。
- 自動出場只是把 app 裡的狀態改成「已出場」,不是真的下單。
- 資料到前一個交易日收盤為止,盤中不要拿這裡的數字當即時價。
